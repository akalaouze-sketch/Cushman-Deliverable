# Frontend layer — NEXT MILESTONE (not yet implemented)

React app mirroring the Cushman & Wakefield MarketBeat report layout:

- Stat callout cards, recharts line/bar charts, narrative blocks.
- AI chat interface to adjust charts, change date ranges, request insights.
- "Market Pulse" news feed at the top, refreshed each session.
- Commentary rendered in the MarketBeat analytical voice.
- Modular **Tools** panel so new capabilities (chart generators, slide builders,
  export functions) can be added without restructuring the app.

Reads only what the server exposes. Built after the data + agent layers.
